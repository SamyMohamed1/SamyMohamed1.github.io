Selected Work

Projects

01

Autonomous Long-Range Strike Drones

Long-range autonomous flight needs dependable behavior in every mission phase, from takeoff through terminal guidance. I designed the guidance logic for those phases and built the ESKF-based sensor fusion for state estimation. I also tuned the cascaded autopilot loops to hold the trajectory under environmental disturbances.

  • ESKF sensor fusion
  • Terminal guidance
  • Waypoint navigation
  • Cascaded autopilot
  • PX4
02

GNC Systems for Autonomous ISR UAVs

ISR missions depend on stable flight, repeatable route execution, and safe handling of faults. I implemented waypoint navigation, loiter, return-to-home, and failsafe modes, and designed the longitudinal and lateral autopilot loops. I validated the system through simulation and flight log analysis.

  • Waypoint & loiter
  • RTH & failsafe modes
  • Autopilot design
  • Flight log analysis
  • SIL testing
03

Interceptor Drones

Intercepting a moving target needs responsive guidance and tightly tuned control. I develop mid-course and terminal guidance using pursuit and proportional navigation laws, and tune the autopilot for tracking accuracy. The guidance runs as real-time embedded software.

  • Mid-course guidance
  • Terminal guidance
  • PP / PN / APN
  • Autopilot tuning
  • Real-time C++ / Rust
04

Modeling & Simulation of Homing and Commanded Guided Missiles

Evaluating guidance concepts early requires high-fidelity models and closed-loop testing. I build dynamic models in Simulink to develop guidance algorithms and controllers, then validate them in closed loop. Homing and command guidance are compared using PP, PN, and APN laws.

  • Simulink
  • Guidance laws
  • Closed-loop validation
  • MIL / SIL / HIL
05

Autonomous Mobile Manipulators

Mobile manipulation couples base motion, perception, and planning, so the autonomy software must be modular and well validated. I contribute to the navigation, state estimation, and motion planning stack, tested in ROS 2 and Gazebo before hardware.

  • ROS 2
  • Gazebo
  • Sampling-based planning
  • State estimation
  • Sensor fusion
